# Playerok Deals

Telegram Mini App для безопасных сделок с эскроу: покупка и продажа
NFT-подарков и других товаров. Интерфейс повторяет референс
(@FunPayExchanger_bot), валюты расширены — добавлены **тенге (KZT)** и
**белорусский рубль (BYN)**.

## Что умеет

* Создание сделки в 4 шага: тип → описание → сумма и способ оплаты → оплата.
* Валюты: RUB, USD, EUR, **KZT**, **BYN**, UAH.
* Способы оплаты под каждую валюту: Карта РФ/СБП, Карта УКР, Kaspi.kz,
  Карта Казахстана, Карта Беларуси (БПС-Скарт), TON-кошелёк, Telegram Stars.
* Статусы сделки с прогресс-баром из 5 шагов и историей переходов.
* Разделы: Сделки, Кошельки (с балансом по каждой валюте), Лидеры, Профиль.
* Отзывы о завершённых сделках.
* Кнопка «Написать менеджеру» (аккаунт задаётся в `.env`).
* Команда `/luxenaction` — заглушка под будущую логику.

## ⚠️ Про интеграцию с FunPay

**Публичного API у FunPay нет.** Есть только внутренние эндпоинты сайта: они
не являются публичным контрактом, могут измениться в любой момент, и их
использование против правил сервиса. Поэтому реальная интеграция
**не реализована** — файл `bot/funpay/live.py` бросает
`ProviderNotImplemented`, а не делает вид, что работает.

По умолчанию бот стартует в режиме `ESCROW_PROVIDER=mock`:
escrow — это честная симуляция, вторая сторона сделки имитируется
автоматически, чтобы полный цикл можно было прокликать. Денег не движется.

Чтобы работать с настоящими сделками, нужно одно из:

1. Официальный / партнёрский доступ от FunPay.
2. Ручной режим: бот собирает заявку и реквизиты, а выпуск средств
   подтверждает менеджер.
3. Свой эскроу-провайдер (ЮKassa, Тинькофф безопасные сделки и т.п.) —
   тогда реализуется свой класс в `bot/funpay/` по образцу `mock.py`.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
pip install -e .
Copy-Item .env.example .env
```

`pip install -e .` ставит проект в editable-режиме, после чего `python -m bot`
работает **из любой папки**, а не только из корня проекта. Без этой команды
Python ищет пакет `bot` только в текущей директории и отвечает
`No module named bot`.

Заполни в `.env`:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `WEBAPP_URL` | публичный HTTPS-адрес Mini App |
| `PORT` | локальный порт (по умолчанию 8080) |
| `MANAGER_USERNAME` | юзернейм менеджера **без @**, например `dealmgr` |

## Запуск

```powershell
python -m bot
```

или, после `pip install -e .`, из любой папки:

```powershell
funpay-deal
```

Telegram открывает Mini App только по **HTTPS**-адресу, поэтому для
локальной разработки нужен туннель:

```powershell
cloudflared tunnel --url http://localhost:8080
# или
ngrok http 8080
```

Полученный адрес вставь в `WEBAPP_URL` и перезапусти бота. После этого
в чате с ботом появится кнопка меню, а `/start` покажет inline-кнопку.

### Отладка интерфейса без Telegram

Включай `DEV_MODE=1` — проверка подписи `initData` отключается и можно
открыть `http://localhost:8080` в обычном браузере. В проде так делать
нельзя.

## Проверка

```powershell
python -m tests.smoke
```

Сквозной тест API без Telegram: конфиг, валидация, сделки в KZT и BYN,
полный жизненный цикл, отзывы, кошельки, лидеры, статика.

## Если что-то не запускается

| Симптом | Причина и решение |
|---|---|
| `No module named bot` | запуск не из папки проекта → `pip install -e .` |
| Python стартует, но падает с `No module named 'encodings'` | битая установка → удалить и поставить заново |
| `python3` открывает Microsoft Store | заглушка Store перехватывает команду |
| `ModuleNotFoundError: aiogram` | зависимости установлены в другой интерпретатор → `python -m pip install -r requirements.txt` |

Проверить, с каким Python ты работаешь:

```powershell
python -c "import sys; print(sys.executable)"
python -m pip --version
```

## Команды бота

| Команда | Действие |
|---|---|
| `/start` | описание сервиса + кнопка приложения |
| `/app`, `/сделки` | открыть приложение |
| `/manager`, `/менеджер` | ссылка на менеджера |
| `/safety`, `/безопасность` | правила безопасной сделки |
| `/luxenaction` | служебная, логируется, ждёт ТЗ |

## Структура

```
bot/
  __main__.py     запуск: бот (long polling) + веб-сервер
  api.py          HTTP-сервер Mini App, проверка подписи initData
  services.py     бизнес-логика сделок, переходы статусов
  db.py           SQLite: сделки, события, отзывы, кошельки
  currencies.py   валюты и способы оплаты
  handlers.py     команды Telegram-бота
  config.py       чтение .env
  funpay/         провайдеры эскроу: base / mock / live
  webapp/         интерфейс Mini App (vanilla JS, без сборки)
tests/
  smoke.py        сквозной тест API
```

## Как задать менеджера

Пропиши в `.env` юзернейм **без @**:

```
MANAGER_USERNAME=dealmgr
```

Кнопка «Написать менеджеру» откроет `https://t.me/dealmgr`.
Пока переменная пустая — бот отвечает, что менеджер не назначен.
